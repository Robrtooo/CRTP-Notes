# General Notes

> [!summary] Résumé
> Note d'introduction à Active Directory : rôle global, intérêt pour l'administration Windows et premières idées à retenir pour la préparation CRTP.

Everything is an object -> so manipulable

Designed to managed a Windows networks

Easily to store data abt special users

> [!NOTE] Microsoft Def
> Active Directory enables centralized, secure management of an entire network, which might span a building, a city or multiple locatons throughout the world.

- C'est utile pour la gestion centralisée d'un réseau Windows.
- La sécurité réelle dépend fortement de la maintenance, des durcissements et de l'hygiène d'administration.
